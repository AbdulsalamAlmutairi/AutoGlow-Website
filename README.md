# AutoGlow - Car Wash Booking System

A single-page web application for booking professional car detailing services online.

## Features
- Browse and select car detailing packages
- User registration and login with localStorage
- Booking system (car type, date, time)
- Checkout with credit card form and VAT calculation
- Booking confirmation with print option
- About Us and Help pages with WhatsApp support

## Technologies
- HTML5 (semantic structure)
- CSS3 (responsive layout and styling)
- JavaScript (SPA navigation, form validation, localStorage)

## File Structure
```
├── index.html
├── css/
│   └── autoglow-styles.css
├── js/
```

## How to Run
Open `index.html` in any modern browser, or visit the GitHub Pages link.
